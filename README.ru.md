# Image Art Converter

[English](README.md) | Русский

Локальное веб-приложение на Python + Streamlit для преобразования изображений в различные художественные стили. Подходит для GitHub-портфолио: весь код открыт, алгоритмы реализованы своими силами без нейросетей и внешних API.

## Возможности

Загрузите изображение (PNG, JPG, JPEG, WEBP) и примените один из эффектов:

| Эффект | Описание | Настройки |
|--------|----------|-----------|
| Оттенки серого | Преобразование в grayscale по формуле luminance (ITU-R BT.601) | Интенсивность |
| Пиксельная графика | Уменьшение разрешения с увеличением через NEAREST + квантование палитры | Размер пикселя, количество цветов, интенсивность |
| Карандашный эскиз | Классический алгоритм color dodge (инверсия + размытие Гаусса + деление) | Интенсивность, контраст |
| Контурная раскраска | Обнаружение контуров (Sobel), нормализация, пороговая бинаризация | Толщина контуров, порог детализации |
| ASCII Art | Яркость пикселей → ASCII-символы, несколько наборов символов | Плотность, набор символов, ширина |

### Экспорт
- Графические эффекты: скачать результат в **PNG**.
- ASCII Art: скачать результат в **TXT**.

### Интерфейс
- Переключатель тёмной / светлой темы.
- Боковая панель с настройками.
- Сравнение оригинала и результата side-by-side.
- Ползунки, переключатели, кнопка сброса настроек.
- Индикатор обработки, уведомления об ошибках.

Вся обработка ведётся локально. Нейросети, внешние API и облачные сервисы не используются.

## Установка

### Требования

- Python 3.11 или новее
- pip

### Windows PowerShell

```powershell
# Клонировать репозиторий
git clone <url-репозитория>
cd "Image Art Converter"

# Создать и активировать виртуальное окружение
python -m venv .venv
.\.venv\Scripts\Activate.ps1

# Установить зависимости
pip install -e .
```

### Linux / macOS

```bash
# Клонировать репозиторий
git clone <url-репозитория>
cd "Image Art Converter"

# Создать и активировать виртуальное окружение
python3 -m venv .venv
source .venv/bin/activate

# Установить зависимости
pip install -e .
```

## Использование

Запуск приложения:

```bash
streamlit run app.py
```

Приложение откроется в браузере по адресу `http://localhost:8501`.

1. Загрузите изображение через боковую панель (PNG, JPG, JPEG, WEBP, максимум 20 МБ).
2. Выберите эффект в боковой панели.
3. Настройте параметры эффекта ползунками.
4. Сравните оригинал и результат side-by-side.
5. Скачайте результат (PNG для графических эффектов, TXT для ASCII Art).

Дополнительная настройка не требуется; приложение работает «из коробки».

## Тестирование

В проекте 46 автоматических тестов, охватывающих каждый алгоритм обработки, RGB и RGBA изображения, изображения разных размеров, некорректные/пустые входные данные и сохранение результатов.

```bash
pytest
```

С покрытием:

```bash
pytest --cov=src/image_converter
```

Все 46 тестов проходят.

## Конфигурация

Файл `.env` и переменные окружения не требуются. Приложение работает без дополнительной настройки.

Лимиты безопасности определены в `src/image_converter/utils/validation.py`:

- Максимальный размер загружаемого файла: 20 МБ
- Максимальное количество пикселей: 64 Мп (защита от чрезмерного потребления RAM)
- Поддерживаемые форматы: PNG, JPEG, WEBP

## Ограничения

- Максимальный размер загружаемого файла: 20 МБ.
- Максимальный размер изображения: 64 мегапикселя.
- Поддерживаемые форматы ввода: PNG, JPEG, WEBP.
- Графические результаты можно скачать в PNG; ASCII Art — в TXT.
- Нейросети и внешние API не используются; эффекты — детерминированные классические алгоритмы.
